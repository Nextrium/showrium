# Third-party notices

Showrium's web app includes open-source software. Most of it is under permissive licences (MIT, Apache-2.0, ISC, BSD). This file lists components whose licences ask for a notice.

## heic-to (LGPL-3.0)

- Used to convert iPhone (HEIC) photos to JPEG in the browser, loaded only when such a photo is chosen.
- Shipped unmodified as a separate file, so it can be replaced with any compatible version.
- Source: https://github.com/hoppergee/heic-to (it bundles libheif, https://github.com/strukturag/libheif, also LGPL-3.0).
- Licence: https://www.gnu.org/licenses/lgpl-3.0.html
