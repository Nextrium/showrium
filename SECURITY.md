# Security

## Reporting a vulnerability

Please **don't** open a public issue for a security problem. Report it privately, in either of these ways:

- GitHub: the **"Report a vulnerability"** button on this repository's **Security** tab
- Email: **support@showrium.com**, with "Security" in the subject

Include what you found, how to reproduce it, and what it could affect. We'll reply within 3 working days, and keep you updated until it's fixed. If you'd like credit when we publish the fix, tell us how to name you.

## Scope

- **In scope:** the code in this repository, and the hosted service at showrium.com and app.showrium.com.
- **Don't** access other people's data, run denial-of-service tests, use social engineering, or test against other people's accounts. Use your own test accounts.

## Supported versions

Fixes go into the latest release (`main`) and the `develop` branch.
